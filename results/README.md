# Selected results

Only compact summary outputs and a few diagnostic figures are committed here. Large coarse grids and raw per-pixel observation tables are omitted and can be regenerated by the corresponding experiment scripts.

## Sensitivity / identifiability

- `03_svd_summary.json` — singular values and condition number for the initial two-parameter, six-channel diagnostic.
- `04_sensor_ablation.csv` — L-only, S-only, co-pol and full L/S SVD comparison.
- `01b_iem_validity_grid.png` — IEM validity-domain diagnostic.
- `02_sweep_*.png` — one-at-a-time parameter sweeps.
- `04b_joint_roughness_salinity_validity.png` — joint surface/salinity model-domain diagnostic.

## Synthetic inversion

- `05_synthetic_summary.json` — known synthetic state, noisy observation and best retrieval.
- `05b_synthetic_cost_surface_summary.json` — clean/noisy cost-surface summary.
- `05b_cost_surface_clean.png`, `05b_cost_surface_noisy.png` — synthetic loss surfaces.

## Real-observation reachability

- `06_forward_model_existence_summary_historical_pre_mean_audit.csv` — initial real-data existence test; retained only as a pre-mean-audit historical diagnostic.
- `06b_expanded_existence_summary_historical_pre_mean_audit.csv` — expanded-bound test from the same pre-mean-audit stage.
- `06c_channel_subset_reachability.csv` — L-only, S-only and joint comparison.
- `09b_incidence_aware_safe_refinement.csv` — actual-incidence reachability with safe derivative-free refinement.
- `10_myi_firstyear_vs_multiyear.csv` — structural FYI-to-MYI comparison.
- `11_myi_length_scale_vs_experiment10.csv` — effect of separating surface and internal MYI length scales.
- `12_myi_semi_constrained_reachability.csv` — tighter internal-MYI constraint test.
- `12_myi_vs_experiment11.csv` — broad vs constrained MYI comparison.
- `13_myi_snow_vs_bare.csv` — first one-layer fresh/dry snow diagnostic.

The CSV/JSON outputs are diagnostic model results, not validated geophysical retrieval products.

## Observation-provenance note

The real-data workflow evolved during the audit. The 06/06b summaries predate the switch to linear-power class averaging. The 06c summary uses the later power-mean observation summary but still uses the empirically incidence-normalized raster products. Experiments 07-08 then rebuild the observations without that empirical normalization and bin them by actual incidence angle; experiments 09b-13 use that later path. These stages should not be mixed as if they were one homogeneous observation product.
